## 2. 爬取通道(已实测验证,可直接用)

### 站点事实

- 库容量 **664,546 条 / 3,533 小时**(官方 sitemap 实测 2026-10-04)
- 体积:1080p ≈15MB/条、4K ≈72MB/条(CDN HEAD 抽样)→ 全库 1080p ≈10–12TB;4K ≈42–48TB
- Pexels License 允许本地缓存/修改/商用(禁止再分发到竞品素材平台/售卖原片)

### 内部 v3 API(核心通道,已验证)

- **全量浏览**:`GET https://www.pexels.com/en-us/api/v3/videos?sort=popular&per_page=24&seo_tags=true`,翻页 = 追加 `&seed=<上一页 pagination.cursor>`(链式唯一性已验证;每页固定 18 条)
- **搜索枚举**:`GET /en-us/api/v3/search/videos?query=<英文词>&per_page=24&page=N`(单查询上限 10,000 条)
- **认证**:请求头 `secret-key: H2jk9uKnhRmL6WPwh89zBezWvr`(这是 **Pexels 前端 JS 的公开常量**,不是个人 API key)+ `x-client-type: react` + 普通浏览器 UA。若被轮换(401),可从 pexels.com 任一页面的 Network 面板/公开 JS bundle 重新派生
- **实测限速**:15 连发全部 200 无 429;直连(不走代理)0.7s/req 且可达(比走 Clash 代理快一倍)
- **响应字段**(远超官方 API):title / description / **完整 tags 数组** / duration / fps / width·height / aspect_ratio / license / user / created_at / `video.video_files`(**全部 rendition 直链 mp4,含 4K**)/ `video.thumbnail`(缩略图 URL)/ download_link
- 规模:全量枚举约 36,900 请求 ≈ 4–7 小时(4–6 并发)

### 浏览器机制(browser-use,已实测)

- 方式:CDP `Runtime.evaluate` 在 pexels 页面上下文执行 `fetch()`(页内 Promise 池 4–6 并发,`awaitPromise=True`);实测 3 请求 2.4s,seed 翻页正常
- **匿名要求**:用**全新专用 Chrome profile / 独立窗口**——用户个人 profile 里有 `pexels_auth` 等 cookie,勿用于爬取
- **降级链**:页内 fetch → UI 驱动(导航 + Load More 点击 + 解析 `__NEXT_DATA__`)→ httpx 直连重放(Plan B,已证明可行)
- **续爬**:seed cursor + 词表进度持久化 checkpoint,随时可重启
- 风险:secret-key 理论上会轮换(挂 401 看门狗);ToS 灰区——礼貌限速、内部 R&D 用途

## 3. 已锁定决策(除非用户明说,不要重开)

### 向量化模型 seam + 选型标注(Phase 2)

接口:`EmbeddingProvider{ dense_text / dense_image / sparse_text }` + `model_id/dim/distance/max_batch`;corpus 与 query 两侧同走;DB 带 `embedding_model` 标识支持双模型过渡与整体换模。

- **Dense 默认起步**:`tongyi-embedding-vision-flash`(768 维,跨模态文搜图,¥0.18/1M tok,与 MPT 现有查重门/粗排**同向量空间**,Key 已在 MPT config `[image_embedding]`)
- **升级候选**:`qwen3-vl-embedding`(768–2560 可选,支持 text+image **融合单向量**,¥0.258/1M,＋44% 成本,试点 A/B 后定)
- 备用:`BGE-M3 @ SiliconFlow`(纯文本路,丢跨模态);本地 CLIP 否决(无 GPU)
- **Sparse 默认起步**:本地 **BM25**(零成本、确定性);对比候选:`BGE-M3 sparse @ SiliconFlow`;待验证:DashScope 是否暴露 sparse 输出
- **评测门**:VLM 采纳率 / 召回@k 对比现行漏斗,达标才切默认
